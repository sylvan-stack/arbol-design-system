04 / Behavior is part of the design

Keep the user's place

Preserve drafts, selection and reading position. Background refresh never pretends to be a new navigation.

Make the result explicit

Saving, saved, failed, stale and partial success are different states. A closed dialog alone is not confirmation.

Use familiar controls

Ordinary click opens. Visible actions edit and link. Keyboard focus stays visible and returns after a dialog.
