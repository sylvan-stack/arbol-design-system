Legacy components are evidence and visual references, not automatically production-ready implementations.\n\n## Composition model\n\nBuild four levels: tokens → accessible primitives → reusable interaction patterns → workspace recipes. The shared package owns interaction mechanics; a workspace owns domain fields, permitted actions and data adapters.
